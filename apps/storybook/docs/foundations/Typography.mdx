# Typography

Quicksand is the only typeface. Amount columns are right-aligned because the
font has proportional figures.

## Scale

<TypeScale />

`--text-2xs` is reserved for legal and footnote text. Display sizes use
`clamp()`.

## Semantic element

`Typography` variants set presentation. The `as` prop sets the document
element when the default heading level does not fit the page.

```tsx
<Typography variant="displayLg" as="h2">
  Section headline
</Typography>
```
