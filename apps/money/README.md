# khata money (`@khata/money`)

Personal finance for Indian households, built on the Calm Kit (`@khata/ui`). Manual entry and
CSV only — no bank or account-aggregator integrations. The feature and technical plan is in
[`docs/money/PLAN.md`](../../docs/money/PLAN.md).

**Features:** accounts (bank, cash, UPI wallet, credit card) · expense/income/transfer entries
with Indian categories and payment modes · monthly budgets · bills, SIPs & EMIs with
mark-paid and loan amortization · savings goals · net worth from manual holdings (FD, RD, PPF,
EPF, NPS, MF, stocks, gold, property) · 80C / 80D / 80CCD(1B) tracker by financial year
(April–March) · reports · CSV import (debit/credit bank statements) and export · GA4 behind a
consent banner.

## Stack

One Cloudflare Worker serves both halves:

| Path          | What                                                                                |
| ------------- | ----------------------------------------------------------------------------------- |
| `src/`        | Vue 3 SPA (Vue Router, TanStack Query), served as Workers static assets             |
| `worker/`     | Hono API under `/api`, Better Auth (Google) at `/api/auth/*`, Drizzle on D1         |
| `shared/`     | zod schemas, API types, and pure money / date / FY / EMI / tax helpers used by both |
| `migrations/` | SQL generated by `drizzle-kit` and applied with `wrangler d1 migrations apply`      |
| `test/`       | Vitest inside workerd (`@cloudflare/vitest-plugin`) against a Miniflare D1          |

Conventions:

- Money is always integer **paise**.
- Dates are ISO `YYYY-MM-DD` and "today" is computed in IST.
- Every app table carries `user_id`, and route handlers filter through `own(table, userId)`.

## Run locally

```bash
cp apps/money/.dev.vars.example apps/money/.dev.vars   # then fill in the values
pnpm --filter @khata/money db:migrate:local
pnpm --filter @khata/money dev                          # http://localhost:5173
```

Without Google credentials, use **Try the demo (dev)** on the landing page. It calls
`POST /api/dev/login`, which exists only when `ENVIRONMENT=dev` and returns 404 in production.

## Deploy

1. Create the database, then put the printed id into both `database_id` fields of `wrangler.jsonc`:

   ```bash
   pnpm --filter @khata/money exec wrangler d1 create khata-money
   ```

2. Create a Google OAuth client (type: Web application):
   - Authorised JavaScript origin: `https://money.khata.club`
   - Authorised redirect URI: `https://money.khata.club/api/auth/callback/google`
3. Set the secrets:

   ```bash
   cd apps/money
   npx wrangler secret put BETTER_AUTH_SECRET --env production    # openssl rand -base64 32
   npx wrangler secret put GOOGLE_CLIENT_ID --env production
   npx wrangler secret put GOOGLE_CLIENT_SECRET --env production
   ```

4. Check `BETTER_AUTH_URL` under `env.production.vars` in `wrangler.jsonc`.
5. Apply migrations and deploy. Set `VITE_GA_MEASUREMENT_ID` at build time to enable GA4.

   ```bash
   pnpm --filter @khata/money exec wrangler d1 migrations apply khata-money --remote --env production
   VITE_GA_MEASUREMENT_ID=G-XXXXXXX CLOUDFLARE_ENV=production pnpm --filter @khata/money deploy
   ```

After changing `worker/db/schema.ts`, run `pnpm --filter @khata/money db:generate` and commit the new
migration.

## Analytics (GA4)

`src/lib/analytics.ts` loads gtag.js only when `VITE_GA_MEASUREMENT_ID` is set.

**Consent:**

- Consent Mode v2 starts with `analytics_storage` denied.
- `ad_*` signals are always denied.
- The banner (or the Settings toggle) grants analytics.

**What gets sent:**

- Page views are sent per route **name**, never a URL containing ids.
- Events never include amounts, names, payees, notes, emails or ids, and counts are bucketed.

**Events:**

- **Auth:** `login`, `sign_up`, `logout`
- **Onboarding:** `onboarding_step`, `onboarding_complete`
- **Accounts:** `account_create`, `account_archive`
- **Entries:** `transaction_add` (type, category, payment mode, source), `transaction_edit`, `transaction_delete`
- **Categories and budgets:** `category_create`, `budget_set`, `budget_copy`
- **Bills, SIPs & EMIs:** `recurring_create`, `recurring_mark_paid`
- **Goals and holdings:** `goal_create`, `goal_contribute`, `holding_add`, `holding_update`
- **Tax and reports:** `tax_view`, `tax_declaration_add`, `report_view`
- **CSV:** `export_csv`, `import_csv_start`, `import_csv_complete`
- **Privacy:** `consent_update`, `data_delete`
